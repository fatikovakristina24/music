# Проверки

Проект работает без npm. Этот необязательный сценарий проверяет его в Chromium с тестовым микрофоном: полифонию и настоящую громкость, LOOP, запись и паузу, WAV, лимит 20 секунд, освобождение микрофона, отличие всех эффектов от исходного звука, изменение частоты при сохранении длительности и desktop-разметку.

Для повторной проверки установи Node.js и Playwright, затем:

```sh
npm install --no-save playwright
npx playwright install chromium
```

Запусти локальный сервер по основной инструкции и в другом терминале выполни:

```sh
node tests/browser.cjs
node tests/regressions.cjs
node tests/visuals.cjs
node tests/mobile.cjs
CONTOUR_WIDTH=768 node tests/mobile.cjs
node tests/melody.cjs
node tests/stereo.cjs
```

Скриншоты, тестовый WAV и отчёт появятся в `test-results/`. Микрофон теста — автоматически созданный синусоидальный сигнал, а не запись человека. Для публикации эта папка не нужна.

Проверка касаний охватывает макеты 414 и 768 px, настоящий звук при игре двумя пальцами, LOOP, микрофон, детский эффект, WAV и отсутствие горизонтальной прокрутки на ширинах 320–1440 px, включая границы телефонной, планшетной и desktop-компоновок. `CONTOUR_WIDTH=768` запускает тот же сценарий на планшете. Проверяется эмуляция в Chromium; это не заменяет проверку на физическом устройстве.

Проверка мелодии проверяет WAV, время нот и пауз, аккорды, длинную последовательность из 40 нот, тембр баса, тишину при нулевой громкости и хвост эха. Скачивание не останавливает текущий повтор.

Проверка стерео измеряет частоты A/B и уровень каждого канала, изоляцию L/R, изменение панорамы, срез фильтра, отдельные хвосты эха и комнаты, независимость настроек, два генератора на каждую живую ноту и два различающихся канала скачанного WAV.
