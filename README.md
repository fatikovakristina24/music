# КОНТУР

Интерактивный веб-синтезатор для учебного проекта по арт-практике. Звук управляет движением центральной формы. Два режима: игра на нотах и обработка собственного голоса.

Проект написан на HTML, CSS и JavaScript. Звук создаётся и обрабатывается через Web Audio API. Фреймворки и сборка не нужны.

Графика использует тёмную палитру с синими и лавандовыми акцентами. У каждой ноты свой рисунок и движение центрального контура: пульсация, треугольник, ромб, вихрь, восьмёрка, цветок, звезда и частая рябь. Цвет формы связан с пэдом. Аккорд смешивает формы нот; сила реакции зависит от громкости звука. На пэдах показаны разные волны.

## Запуск

Открой `index.html` через расширение **Live Server** в VS Code. Другой способ — выполнить из папки проекта:

```sh
python3 -m http.server 4173
```

Открой [localhost:4173](http://localhost:4173). Для микрофона и аудиомодулей нужен localhost или HTTPS; открытие HTML двойным кликом не подходит.

Для GitHub Pages выбери **Settings → Pages → Deploy from a branch → main → / (root)**. Все пути относительные.

## Управление

- **Играть:** нажимай пэды мышью или клавиши **A S D F G H J K**. Подходит и русская раскладка. Можно удерживать несколько нот одновременно.
- **Звучание:** три тембра, длительность затухания, эхо и громкость.
- **Твоя фраза:** запись мелодии до 20 секунд с автоматической остановкой. «Повтор» воспроизводит записанные ноты по кругу; звучание можно менять.
- **Мой голос:** запись с микрофона до 20 секунд. Доступны прослушивание, пауза, сброс эффектов, удаление и скачивание WAV.
- **Эффекты голоса:** высота, детский голос, робот, эхо, комната, искажение и радио. Эффекты можно сочетать и менять при прослушивании. Детский голос поднимает высоту до 7 полутонов и осветляет тембр. Изменение высоты сохраняет скорость речи, придавая голосу электронную фактуру.
- **Скачать запись:** текущие настройки применяются ко всей фразе, включая хвосты эха и реверберации. Оригинал остаётся доступен через «Без эффектов».

Голос хранится в памяти вкладки и не отправляется на сервер. Перезагрузка удаляет запись. Мелодия хранится как последовательность нот. При смене режима воспроизведение останавливается. Пробел управляет прослушиванием голоса, когда фокус не на кнопке или ползунке.

## Структура проекта

| Файл                    | Назначение                                              |
| ----------------------- | ------------------------------------------------------- |
| `index.html`            | Разметка инструмента и инструкция                       |
| `styles.css`            | Оформление, состояния элементов и адаптация для desktop |
| `assets/`               | Шрифты, лицензия, иконка и контуры формы                |
| `js/app.js`             | Интерфейс, клавиатура и мышь                            |
| `js/visuals.js`         | Визуальная реакция на громкость, частоту и ноты         |
| `js/note-motion.js`     | Формы и цвета восьми нот, смешивание контуров           |
| `js/loop.js`            | Запись и повтор мелодии по аудиочасам                   |
| `js/voice.js`           | Микрофон, запись и скачивание                           |
| `js/audio/engine.js`    | Генерация нот и воспроизведение голоса                  |
| `js/audio/effects.js`   | Цепочка голосовых эффектов                              |
| `js/audio/pitch-dsp.js` | Изменение высоты голоса                                 |
| `js/audio/worklets.js`  | Обработка и захват звука в аудиопотоке                  |
| `js/audio/wav.js`       | Формирование WAV-файла                                  |
| `tests/`                | Автоматические проверки; не нужны для запуска сайта     |

«Робот» использует кольцевую модуляцию, «Эхо» — задержку с обратной связью, «Комната» — свёртку с импульсом, «Искажение» — насыщение, «Радио» — частотные фильтры. Высота меняется через два перекрывающихся звуковых фрагмента. Компрессоры ограничивают пики сигнала.

## Дизайн и проверка

[Макет Figma](https://www.figma.com/design/V4pHlkrNFszzDCHklpWUcg/?node-id=177-3493). Основной размер — 1440 × 960 px. В узком окне весь макет пропорционально уменьшается, сохраняя композицию. Шрифт Manrope подключён локально; лицензия находится в `assets/OFL.txt`.

Проверки охватывают аккорды, громкость, запись и повтор мелодии, запись голоса, семь эффектов, WAV, лимиты записи, освобождение микрофона и восстановление после отказа доступа. Инструкция — в [tests/README.md](tests/README.md). Тесты используют искусственный сигнал; качество звучания своего голоса стоит оценить на настоящем микрофоне.
