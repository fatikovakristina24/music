# КОНТУР

Интерактивный веб-синтезатор для учебного проекта по арт-практике. Звук управляет движением центральной формы. Первый раздел — создание мелодии двумя голосами A и B; второй — обработка собственного голоса.

Проект написан на HTML, CSS и JavaScript. Звук создаётся и обрабатывается через Web Audio API. Фреймворки и сборка не нужны.

Графика использует тёмную палитру с синими и лавандовыми акцентами. У каждой ноты свой рисунок и движение центрального контура: пульсация, треугольник, ромб, вихрь, восьмёрка, цветок, звезда и частая рябь. Цвет формы связан с пэдом. Аккорд смешивает формы нот; сила реакции зависит от громкости звука. На пэдах показаны разные волны.

## Запуск

Открой `index.html` через расширение **Live Server** в VS Code. Другой способ — выполнить из папки проекта:

```sh
python3 -m http.server 4173
```

Открой [localhost:4173](http://localhost:4173). Для микрофона и аудиомодулей нужен localhost или HTTPS; открытие HTML двойным кликом не подходит.

Для GitHub Pages выбери **Settings → Pages → Deploy from a branch → main → / (root)**. Все пути относительные.

## Управление

- **Играть:** нажимай пэды мышью, касанием на телефоне или клавиши **A S D F G H J K**. Подходит и русская раскладка. Можно удерживать несколько нот одновременно, в том числе несколькими пальцами.
- **Два голоса:** A и B звучат одновременно при каждом нажатии. Переключатель выбирает голос для настройки, а не отключает другой. У каждого свои тембр, фильтр (100–6000 Hz), эхо (0–60 %), комната (0–100 %), громкость (0–100 %) и панорама (L–R). Затухание нот 0.1–4 s общее. По умолчанию A — мягкий синус в левом канале, B — басовый треугольник на октаву ниже в правом. Для прослушивания одного голоса опусти громкость другого до нуля.
- **Твоя мелодия:** запись мелодии до 20 секунд с автоматической остановкой. «Повтор» воспроизводит записанные ноты по кругу; звучание можно менять. «Скачать WAV» сохраняет один проход мелодии с текущими настройками обоих голосов, их панорамой, затуханием и хвостами эффектов в двухканальном WAV.
- **Мой голос:** запись с микрофона до 20 секунд. Доступны прослушивание, пауза, сброс эффектов, удаление и скачивание WAV.
- **Эффекты голоса:** высота, детский голос, робот, эхо, комната, искажение и радио. Эффекты можно сочетать и менять при прослушивании. Детский голос поднимает высоту до 7 полутонов и осветляет тембр. Изменение высоты сохраняет скорость речи, придавая голосу электронную фактуру.
- **Скачать запись:** текущие настройки применяются ко всей фразе, включая хвосты эха и реверберации. Оригинал остаётся доступен через «Без эффектов».

Голос хранится в памяти вкладки и не отправляется на сервер. Перезагрузка удаляет запись. Мелодия хранится как последовательность нот. При смене режима воспроизведение останавливается. Пробел управляет прослушиванием голоса, когда фокус не на кнопке или ползунке.

## Структура проекта

| Файл                        | Назначение                                                            |
| --------------------------- | --------------------------------------------------------------------- |
| `index.html`                | Разметка инструмента и инструкция                                     |
| `styles.css`                | Оформление, состояния и адаптация для компьютера, планшета и телефона |
| `assets/`                   | Шрифты, лицензия, иконка и контуры формы                              |
| `js/app.js`                 | Интерфейс, клавиатура, мышь и касания                                 |
| `js/visuals.js`             | Визуальная реакция на громкость, частоту и ноты                       |
| `js/note-motion.js`         | Формы и цвета восьми нот, смешивание контуров                         |
| `js/loop.js`                | Запись и повтор мелодии по аудиочасам                                 |
| `js/voice.js`               | Микрофон, запись и скачивание                                         |
| `js/audio/engine.js`        | Генерация нот и воспроизведение голоса                                |
| `js/audio/synth-channel.js` | Независимые фильтр, эхо, комната, громкость и панорама A/B            |
| `js/audio/effects.js`       | Цепочка голосовых эффектов                                            |
| `js/audio/pitch-dsp.js`     | Изменение высоты голоса                                               |
| `js/audio/worklets.js`      | Обработка и захват звука в аудиопотоке                                |
| `js/audio/wav.js`           | Формирование WAV-файла                                                |
| `tests/`                    | Автоматические проверки; не нужны для запуска сайта                   |

«Робот» использует кольцевую модуляцию, «Эхо» — задержку с обратной связью, «Комната» — свёртку с импульсом, «Искажение» — насыщение, «Радио» — частотные фильтры. Высота меняется через два перекрывающихся звуковых фрагмента. Компрессоры ограничивают пики сигнала.

## Дизайн и проверка

[Макет Figma](https://www.figma.com/design/V4pHlkrNFszzDCHklpWUcg/?node-id=177-3493). Основной размер — 1440 × 1088 px. На телефонах до 600 px используется отдельная компоновка по [мобильному макету 414 px](https://www.figma.com/design/V4pHlkrNFszzDCHklpWUcg/?node-id=292-6928): пэды в два ряда, настройки ниже и кнопки для касания. Для ширин 601–1100 px сделан [планшетный макет 768 px](https://www.figma.com/design/V4pHlkrNFszzDCHklpWUcg/?node-id=340-8229): крупная форма, пэды 4 × 2, параметры звука в два ряда и эффекты голоса в две колонки. На узких планшетах до 700 px параметры звука располагаются вертикально. На компьютере композиция сохраняет пропорции. Два шрифта подключены локально: Unbounded Medium для названия и основных заголовков, Manrope для нот, управления и инструкций. Лицензии находятся в `assets/OFL.txt` и `assets/unbounded-OFL.txt`.

Проверки охватывают аккорды, громкость, запись и повтор мелодии, запись голоса, семь эффектов, WAV, лимиты записи, освобождение микрофона и восстановление после отказа доступа. Инструкция — в [tests/README.md](tests/README.md). Тесты используют искусственный сигнал; качество звучания своего голоса стоит оценить на настоящем микрофоне.

## Соответствие требованиям 4–8

4. В разделе мелодии два одновременно звучащих голоса, а не два взаимоисключающих режима. Цепочка каждого: осциллятор → формирование тембра и огибающая → регулируемый фильтр → эхо → реверберация → громкость → стереопанорама. Независимые цепочки сходятся на общем выходе с ограничением пиков. A по умолчанию выходит в L, B — в R; панораму можно менять. WAV сохраняет оба канала. Запись собственного голоса — дополнительный отдельный раздел.
5. Концепция КОНТУРА — звук оставляет графический след. Восемь нот формируют разные контуры, а аккорд смешивает их; сила движения учитывает реальный уровень сигнала.
6. Интерфейс, генерация звука, запись нот, микрофон, эффекты и визуализация разделены на модули. Структура и сигнальные цепочки показаны на слайде 12.
7. Визуальная система использует Unbounded и Manrope, тёмный фон, синие и лавандовые акценты, контурную графику. Пэды, ползунки, тембры, кнопки и режимы имеют состояния; их компоненты собраны в Figma.
8. Нейминг в Figma: `K / компонент / устройство / голос / параметр`, состояния пэдов — `Default / Hover / Pressed / Release / Focus`, тембры — `Soft / Deep / Bright`. В коде используются `.pad`, `.slider`, `.layer-switch`, `.loop-panel` и модули `AudioEngine`, `NoteLoop`, `VoiceRecorder`, `SoundVisuals`. Нейминг показан на слайде 14, маппинг — на слайде 13: A–K соответствуют До4–До5, ползунки изменяют реальные параметры цепочек.

Разделы сайта сохранены в прежнем порядке: **«Играть» — мелодия**, затем **«Мой голос» — запись и обработка речи**. Переключение разделов останавливает воспроизведение; переключение A/B внутри мелодии выбирает только редактируемый голос.
