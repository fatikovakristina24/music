# КОНТУР

Учебный проект по арт-практике: звук становится формой. Desktop-инструмент с двумя режимами — синтезатор и эффекты собственного голоса. HTML, CSS и JavaScript без фреймворков, сборки и платных сервисов.

## Запуск

Открой папку проекта в VS Code и запусти `index.html` через расширение **Live Server**. Или в терминале из папки проекта:

```sh
python3 -m http.server 4173
```

Затем открой **http://localhost:4173**. Простое открытие файла двойным кликом не подходит: микрофон, модули JavaScript и AudioWorklet требуют локального сервера или HTTPS.

На GitHub Pages размести эту папку целиком и выбери публикацию из корня репозитория. Никаких дополнительных команд сборки не нужно. Относительные пути работают и в адресе вида `username.github.io/repository/`.

## Как пользоваться

- **Играть:** нажимай пэды мышью или физические клавиши **A S D F G H J K**. Русская раскладка тоже подходит. Несколько клавиш одновременно дают аккорд.
- **Звучание:** «Мягкий», «Басовый», «Яркий». Длина звука определяет затухание после отпускания. Эхо и громкость меняются во время игры.
- **Твоя фраза:** нажми «Записать», сыграй и нажми «Остановить»; через 8 секунд запись закончится сама. «Повтор» запускает LOOP. Пресеты и настройки можно менять во время повторения.
- **Мой голос:** разреши микрофон, запиши фразу до **20 секунд**, останови раньше при желании. Запись не звучит в колонках во время захвата.
- **Эффекты:** высота голоса, робот, эхо, комната, искажение, радио. Их можно сочетать и менять прямо при прослушивании. Высота меняется без ускорения речи; обработка имеет лёгкую электронную фактуру.
- **Без эффектов:** возвращает оригинальное звучание. Оригинал хранится отдельно от обработки.
- **Скачать запись:** сохраняет WAV с текущими эффектами и их хвостами. После изменения параметров можно скачать другой вариант. Если параметры менялись во время прослушивания, экспорт применяет последние выбранные значения ко всей фразе.
- **Пауза/продолжение:** кнопкой; пробелом, когда фокус не на другом элементе управления.

Голос находится только в памяти этой вкладки: сервер его не получает. После перезагрузки запись исчезает. LOOP записывает ноты, а не голос. Режимы работают по отдельности. При смене режима воспроизведение останавливается. Для длинной фразы удобно сначала записать голос, затем подобрать эффекты.

## Структура

```text
index.html                 — смысловая структура двух режимов и инструкции
styles.css                 — палитра, шрифт, геометрия и состояния интерфейса
assets/                    — локальные шрифты, контуры из Figma, иконка
js/app.js                  — управление интерфейсом, мышью и клавиатурой
js/visuals.js              — визуализация по анализу реального аудиосигнала
js/loop.js                 — запись нажатий и повтор по аудиочасам
js/voice.js                — микрофон, запись, пауза, скачивание
js/audio/engine.js         — генерация нот, аудиомикшер, воспроизведение
js/audio/effects.js        — цепочка шести эффектов и рендер WAV
js/audio/pitch-dsp.js      — изменение высоты без изменения длительности
js/audio/worklets.js       — обработка в аудиопотоке и захват PCM
js/audio/wav.js            — упаковка обработанного звука в WAV
```

Весь звук синтезатора создаётся Web Audio API. «Робот» — кольцевая модуляция; «Эхо» — задержка с повтором; «Комната» — свёртка с импульсом; «Искажение» — насыщение с компенсацией уровня; «Радио» — ограничение частот. Компрессоры ограничивают пики при сочетании звуков. Высота обрабатывается двумя перекрывающимися звуковыми фрагментами; изменение не растягивает запись.

Шрифт Manrope хранится локально и распространяется по SIL Open Font License. Палитра и контуры соответствуют [утверждённому макету Figma](https://www.figma.com/design/V4pHlkrNFszzDCHklpWUcg/?node-id=177-3493). Основной размер — 1440 × 960; более узкие desktop-окна сохраняют структуру. Минимальная ширина интерфейса — 960 px.

Технические справочники: [Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API), [AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Using_AudioWorklet).

## Проверка реализации

Проверено в Chromium 151: первый короткий клик, аккорды, реальное отключение громкости, запись и повтор LOOP, запись тестового микрофона, пауза/продолжение, сброс и удаление, скачивание WAV, автоматическая остановка на 20 секундах, освобождение микрофона, отказ доступа и повторная попытка. Аудиопроверки подтвердили отличие всех шести эффектов от оригинала и изменение 440 Гц до примерно 880/220 Гц во время прослушивания. Скорость записи сохраняется. Проверены расположение основных блоков на 1440 px и отсутствие горизонтального переполнения на 1024 px.

Тестовый микрофон использует искусственный сигнал; отдельно на настоящем микрофоне можно оценить выбранное звучание под свой голос. Сценарии повторной проверки находятся в `tests/`.
